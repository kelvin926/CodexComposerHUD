# Codex Composer HUD

공식 Windows Codex 앱의 입력창에 컨텍스트 사용량 버튼과 한국어 팝업을 추가합니다.

## 설치형 실행

`CodexComposerHUD-Setup.exe`를 실행해 설치합니다. 현재 사용자 계정에 설치하므로 관리자 권한이 필요하지 않습니다. 바탕화면과 시작 메뉴의 `Codex Composer HUD` 아이콘으로 실행합니다. 설치 후 실행 옵션을 선택하면 기존 표시기를 종료하고 새 버전을 연결합니다.

설치 경로는 `%LOCALAPPDATA%\Programs\CodexComposerHUD`입니다. Windows 설정의 설치된 앱에서 `Codex Composer HUD`를 제거할 수 있습니다. 별도 자동 시작 등록은 하지 않습니다. 이 표시기로 실행한 Codex가 이미 열려 있으면 재시작 없이 다시 연결합니다.

## ZIP으로 실행

1. ZIP 전체를 원하는 폴더에 압축 해제합니다.
2. `Codex Composer HUD.exe`를 실행합니다. 별도 설치나 관리자 권한이 필요하지 않습니다.
3. Codex가 이미 실행 중이면 작업을 마친 뒤 완전히 종료합니다. 표시기가 사용량 버튼이 추가된 공식 앱을 자동으로 엽니다.
4. 모델 선택기 왼쪽의 `컨텍스트 24% | 주간 잔여 15%` 표시를 누릅니다. 수치는 실시간 값입니다.

앞으로도 이 실행 파일로 Codex를 열면 표시기가 함께 실행됩니다. 공식 바로가기로 실행한 Codex에는 자동으로 적용되지 않습니다.

`Stop HUD.exe`를 실행하면 표시기 프로세스와 추가 UI가 제거됩니다. Codex를 완전히 종료하고 공식 바로가기로 다시 열면 평소 상태로 돌아옵니다. 디버깅 포트도 앱이 종료될 때 닫힙니다.

## 표시하는 값

- 컨텍스트: 마지막 요청의 입력 토큰을 실제 모델 컨텍스트 한도와 비교합니다. 계정 또는 세션의 누적 사용량을 컨텍스트로 계산하지 않습니다.
- 토큰 상세: 현재 입력, 캐시된 입력, 최근 출력, 출력 중 추론, 세션 누적 토큰입니다. 캐시는 입력의 일부이고, 추론은 출력의 일부이므로 각각 더하지 않습니다.
- 계정 한도: 앱이 반환하는 한도 기간, 사용률, 초기화 시간입니다. 5시간이나 주간 한도가 반환되지 않으면 가상의 수치를 만들지 않습니다.
- 입력창 요약: 컨텍스트는 사용한 비율, 주간 한도는 남은 비율입니다. 주간 잔여량은 `100 - 사용률`로 계산하며 주간 데이터가 없으면 `—`로 표시합니다. 한도는 앱의 알림과 1분 간격 조회로 갱신합니다.
- 실행 상태: 실행 중인 작업의 경과 시간과 새 이벤트로 확인한 도구 수입니다.
- 자동 압축: 앱이 반환한 설정의 토큰 기준을 마지막 요청의 총 토큰과 비교한 추정값입니다. 설정이 없거나 압축 후 본문만 세는 방식이면 기준 미제공으로 표시합니다. 실제 자동 압축 시점은 엔진과 모델 조건에 따라 달라질 수 있습니다.
- 세션 압축: 작업이 끝난 채팅에서 버튼을 누르면 앱의 `thread/compact/start`로 문맥 요약을 시작합니다. 실행 중인 작업에는 버튼이 비활성화됩니다.
- 비용: 최근 토큰과 세션 누적 토큰을 현재 모델의 기본 API 요금으로 환산한 추정 범위입니다. 입력에서 캐시된 입력을 분리하며 출력에 포함된 추론은 더하지 않습니다. 세션 누적은 과거의 모델 변경이나 요청별 처리 요금을 정확히 복원한 청구액이 아닙니다. Fast 처리, 지역 추가 요금, 도구 사용 요금은 포함하지 않습니다. 구독의 실제 추가 결제액과 구분해야 합니다.
- 캐시 히트: 최근 요청과 세션 누적의 캐시 입력 토큰 / 전체 입력 토큰입니다. 입력이 없거나 데이터가 없으면 미제공입니다.
- 세션 소모와 비용 환산은 기본적으로 접힌 토글바이며, 각각의 제목을 눌러 펼칩니다. 산정 설명도 따로 접을 수 있습니다. 접힘 상태는 팝업을 다시 열거나 데이터가 갱신되어도 유지됩니다.
- 주간 소모: 해당 세션 로그의 가장 이른 한도 기록부터 관측된 계정 사용률 증가를 표시합니다. %p는 주간 전체 한도의 퍼센트포인트입니다. 함께 쓰는 세션이나 다른 기기의 사용도 포함될 수 있으므로 정확한 단독 세션 청구량으로 해석하지 않습니다.
- 시간당 소모와 고갈: 최근 30분 작업 시간의 관측 변화로 추정하며 쉬었던 시간은 제외합니다. 최근 변화가 없으면 세션 작업 평균을 사용합니다. 5분 작업 또는 한도 변화가 부족하면 고갈 시각을 만들지 않습니다. 주간 초기화가 먼저 오면 이를 표시합니다.
- credit: 요청별 누적 토큰의 증가량을 기록된 모델의 Codex credit 요율로 환산합니다. 캐시 쓰기 추가 비용과 API 긴 문맥 할증을 credit에 적용하지 않습니다. 기록된 Fast는 2배, Astra Ultrafast는 6배입니다. 속도가 기록되지 않으면 기본과 지원 속도의 요율 범위로 표시합니다. 중복된 토큰 기록은 두 번 계산하지 않습니다. 지원 요율이나 기록이 없으면 미제공 또는 확인한 부분의 하한으로 표시합니다.
- 잔액 차감: 세션에 기록된 credit 잔액과 현재 계정 잔액의 관측 감소량입니다. 환산된 사용 credit과 별개이며, 포함 한도로 작업하는 동안 잔액 차감은 0일 수 있습니다. 계정 공유, 잔액 조정, 만료에 영향을 받습니다.
- 데이터가 없거나 조회가 실패하면 미제공 또는 오류로 표시합니다. 메시지, 시스템 프롬프트, 도구, Skills별 정확한 분류는 제공되지 않아 표시하지 않습니다.

로컬 세션 파일은 현재 채팅의 기록만 읽으며 변경분을 이어서 읽습니다. 원격 채팅은 해당 호스트가 보내는 새 토큰 이벤트를 이용합니다. 원격의 과거 토큰 사용량은 새 이벤트 전까지 표시되지 않을 수 있습니다.

주간 소모와 credit은 선택한 로컬 세션을 한 번 읽어 과거 기록을 복원하고 이후에는 변경분만 읽습니다. 원격의 과거 한도 기록을 가져올 수 없으면 소모 추정은 미제공으로 표시합니다. 한도 초기화와 잔여량 증가가 확인되면 현재 주간 주기의 관측 기준을 다시 잡습니다.

## 적용 방식

앱을 localhost 디버깅 포트로 실행한 뒤 화면 메모리에 UI를 주입합니다. `WindowsApps`, `app.asar`, 로그인 정보, `config.toml`, 기존 바로가기, 대화 내용은 변경하지 않습니다. 표시기는 계정 토큰이나 쿠키를 직접 읽지 않으며 앱의 기존 조회 연결을 사용합니다. 앱의 내부 UI 구조에 의존하므로 공식 업데이트 후에는 수정이 필요할 수 있습니다.

디버깅 포트는 해당 컴퓨터에서만 열립니다. 같은 컴퓨터의 다른 프로세스도 앱 디버깅에 접근할 수 있으므로 사용을 마치면 앱을 완전히 종료해 포트를 닫을 수 있습니다.

프로그램 상태와 대화 내용 없는 진단 로그는 `%LOCALAPPDATA%\CodexComposerHUD`에 저장됩니다. 실행 파일을 두 번 눌러도 표시기를 중복 실행하지 않습니다. 자동 시작 등록이나 외부 서버 설치는 하지 않습니다.

## 검증 및 소스

`tests`의 Node 테스트와 공식 앱의 별도 테스트 프로필에서 UI 삽입, 실제 계정 한도 조회, 세션 토큰 읽기, 채팅 전환, 중복 삽입 방지, 제거를 확인했습니다. 검증한 Microsoft Store 패키지는 `OpenAI.Codex 26.928.2636.0`입니다.

프로그램 소스는 `launcher.mjs`, `lib`, `ui`, `launcher.cs`입니다. 함께 제공된 Node 런타임으로 실행되므로 Node 설치가 필요하지 않습니다. 런타임의 라이선스는 `runtime/Node-LICENSE.txt`에 있습니다.

빌드: Windows .NET Framework의 `csc.exe /target:winexe /reference:System.Windows.Forms.dll /out:"Codex Composer HUD.exe" launcher.cs`. 실행 파일은 런타임을 숨겨서 시작하는 작은 실행기입니다.
