# Icon source

The application icon was generated with the built-in Imagegen tool, then resized and packaged into PNG, ICO and ICNS without changing the artwork. The generated design is not an OpenAI logo.

Prompt:

Use case: logo-brand. Asset type: production desktop application icon for an unofficial Codex Composer HUD utility. Create one polished, highly legible icon at 1024 by 1024 pixels, centered on a transparent canvas. A charcoal rounded-square tile contains a simple white terminal/code glyph and a clean blue-to-teal circular usage gauge, reflecting the existing HUD's blue progress and teal cache colors. Keep the silhouette bold and the details sparse so it reads at 16 and 32 pixels. Flat, crisp, precise UI icon style with generous spacing and balanced geometry; no 3D mockup, no desk, no decorative scene, no letters, no numbers, no watermark, no OpenAI or other company's logo. The area outside the tile must have genuine transparent alpha. Return only the finished single icon.
